# Qwen3.8-27B on Radeon 890M (gfx1150)

Measured 2026-08-30 on a Framework-class CachyOS box. Same **weight quant + KV type + MTP knobs** as the 7900 XTX recipe in [bench.md](bench.md) so decode is comparable. Throughput is not.

| | |
|---|---|
| **Hardware** | Ryzen AI 9 HX 370, Radeon 890M (gfx1150, 16 CUs, RDNA 3.5) |
| **Memory** | 48 GB UMA VRAM (kernel `VRAM: 49152M`), ~16 GB host RAM left |
| **ROCm** | 7.2.4 (`/opt/rocm`, `hipconfig 7.2.53211`) |
| **OS** | CachyOS (`linux-cachyos` 7.2.2) |
| **Model** | Qwen3.8-27B **Q4_K_M** (~15.65 GiB). Not a larger quant. |
| **KV** | `-ctk q4_0 -ctv q4_0` (same as the XTX max-ctx recipe) |
| **Context** | native 262144 fits on 48 GB with q4 KV (~22 GB total). q8 and f16 KV also fit; left for later. |

XTX numbers below are the 2026-08-17 lemonade b1311 sweep (96 CUs, GDDR6). 890M is ~8–10× slower (16 CUs, LPDDR).

## Recipe flags (890M)

```text
-c 262144 -ngl 99 -fa on
-ctk q4_0 -ctv q4_0
-b 2048 -ub 512 -t 8
--spec-type draft-mtp --spec-draft-n-max 1
```

Vs the XTX command: `gfx1150` binary (not `gfx110X`), `-t 8` (4 Zen 5 P-cores × SMT; more threads steal LPDDR from the iGPU), `-b 2048 -ub 512` (16 CUs; XTX used 4096/2048). Keep K and V the same type — `q8_0-K` + quantized-V deadlocks FA prefill at 32K+ on this ROCm stack.

## Prefix HIP build (this tree)

lemonade `b10469` / `b1317` cannot load DFlash2 (`done_getting_tensors: wrong number of tensors; expected 81, got 58`). This repo's `dflash2.patch` (PR 27342) is the layout that file uses.

No sudo. Portable cmake/ninja, prefix `~/llamacpp-dflash2`, **only gfx1150**, `GGML_HIP_NO_VMM=ON` (this APU reports `VMM: no`).

```bash
# from a clone of this repo, after: tar xf llama.cpp-0.2.0.tar.gz && patch -d llama.cpp-0.2.0 -p1 < dflash2.patch
AMDGPU_TARGETS=gfx1150 PREFIX=$HOME/llamacpp-dflash2 ./scripts/build-prefix.sh
. ~/llamacpp-dflash2/env.sh
llama-cli --list-devices
# ROCm0: AMD Radeon 890M Graphics (49152 MiB, ~48976 MiB free)
```

`makepkg -si` with `AMDGPU_TARGETS=gfx1150` is the same tree if you have `cmake`/`ninja`/`rocm-hip-sdk` from pacman.

## Stock Q4_K_M (lemonade b10469)

`llama-bench` / `llama-server`, 3 reps. Engine: lemonade HIP gfx1150 `b10469` (`666f8898a`). Model: `lmstudio-community/Qwen3.8-27B-GGUF` Q4_K_M.

| test | 890M t/s | XTX t/s | 890M / XTX |
|---|---:|---:|---:|
| pp512 | 103.94 ± 1.38 | — | — |
| **pp2048** | **104.38 ± 0.42** | **~1058** | **0.099×** |
| pp8192 | 96.08 ± 0.16 | — | — |
| tg128 @ d2048 (no spec) | **4.32 ± 0.00** | **34.8** | **0.124×** |
| tg128 @ d8192 (no spec) | 2.71 ± 0.89 | ~35 (flat) | — |
| greedy n=128 + **MTP n-max 1** | **5.84** (5.82 / 5.94 / 5.77) | **46.0** | **0.127×** |

MTP via `llama-server -c 8192`, temp 0. Accept **70.3%** (52/74), mean draft length 1.70. Relative gain **+35%** vs 4.32 (XTX was +32%). 256K prefill not timed (~40 min/run at these rates).

## Blackfrost abliterated Q4_K_M ± DFlash2

Same 890M flags, `llama-server -c 8192`, greedy. Target `Qwen3.8-27B-ABLITERATED-Q4_K_M.gguf` + sidecar `dflash-Qwen3.8-27B-ABLITERATED-BF16.gguf` (3.59 GiB).

| engine | mode | mean decode t/s | accept | vs none |
|---|---|---:|---|---|
| lemonade b10469 | no spec | **4.36** (4.35 / 4.37 / 4.36) | — | 1.00× |
| lemonade b10469 | MTP n-max 1 | **6.06** (6.10 / 6.06 / 6.02) | 55/72 (76%) | **+39%** |
| lemonade b10469 | DFlash2 n-max 3 | **did not load** (81 vs 58 tensors) | — | — |
| **this tree, gfx1150 prefix** | DFlash2 n-max 4 | **6.45** (one 64-token smoke) | 42/80 (52.5%) | ~+48% vs none |

Patched server log: `block_size=8, mask_token_id=248070, n_extract=5, sample_from_anchor=true` — DFlash2, not DFlash1. HIP free memory on this binary is honest (~48 GB free of 49 GB). The 6.45 figure is **not** a 3-rep median.

```bash
. ~/llamacpp-dflash2/env.sh
llama-server \
  -m ~/models/Qwen3.8-27B-ABLITERATED-Q4_K_M.gguf \
  -md ~/models/dflash-Qwen3.8-27B-ABLITERATED-BF16.gguf \
  --spec-type draft-dflash --spec-draft-n-max 4 --spec-draft-ngl 99 \
  -c 8192 -ngl 99 -fa on -ctk q4_0 -ctv q4_0 \
  -b 2048 -ub 512 -t 8 \
  --host 127.0.0.1 --port 8080
```

Fastest *measured* path on this APU is still **embedded MTP n-max 1** if you want a 3-rep number (6.06 t/s). DFlash2 at least runs now; re-bench n-max 4 vs MTP n-max 1 before calling a winner.

## Caveats

- 48 GB is a BIOS UMA carve-out. `free -h` only shows the leftover ~16 GB. Keep mmap. Do not `--no-mmap`.
- lemonade HIP "free" on gfx1150 is often a lie; trust `VRAM: 49152M` and this prefix build's device list.
- Sampler `TOP_K` is not on ROCm0 — sampling stays on CPU (`-t 8`).
- Asymmetric `q8_0-K` + quantized-V: skip (FA prefill deadlock).
